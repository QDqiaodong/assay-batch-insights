# Data provenance

All bundled records are original synthetic examples created for this project,
including `timed_calibrations.csv` and `timed_results.csv`, which use fictional
calibration version identifiers and timestamps.
They describe fictional entities and are not measurements, customers, service
history, official standards, or records copied from another project.
They are distributed under the repository MIT license. No external dataset or
third-party source code is vendored. Dependencies retain their own licenses.
